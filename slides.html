Section 1 · 개념 이해

바이브 코딩(Vibe Coding)이란?

문법을 외우는 것이 아니라, AI에게 명확한 맥락과 사각지대 없는 의도를 디렉팅하는 개발

⚠️ 잘못된 바이브 코딩
• 지시의 부재 & 사각지대: 빈 공간을 AI가 추측하게 방치
• "알아서 적당히 만들어줘" 식의 모호한 요청
• 플랫폼 하네싱(도구, 터미널, 컨텍스트)을 무시한 소통
• 현상: 환각이 아니라 지시 결손으로 인한 엉뚱한 결과
✨ 올바른 바이브 코딩
• 세세한 디렉팅(Directing): 의도와 제약조건을 명확히 명시
• 스펙 작게 쪼개기: DB 구조 → 화면 UI → 인터랙션 단계 분할
• 도구 기반 피드백: 에러 로그 공유 및 실시간 시각적 검증
• 현상: 사각지대를 메워 신뢰성 높은 결과 도출
💡 "현대 AI 플랫폼의 하네싱은 이미 강력합니다. 지금 발생하는 오류는 환각이 아니라 지시의 사각지대에서 생깁니다."
Section 2 · 15분 환경 세팅

실패 확률 0% 환경설정 체크

오늘 우리는 복잡한 인증 절차를 한 방에 통과하는 치트키를 사용합니다.

🐙
1. GitHub 계정 하나로 통일
Supabase, Vercel 모두 별도 가입 없이 [Continue with GitHub]로 1초 로그인

2. 필수 도구 3종 확인

🛡️
3. OS별 단골 지뢰 방어
• 🪟 Win: 스크립트 실행 오류 시 `Set-ExecutionPolicy RemoteSigned`
• 🍎 Mac: 보안 경고 시 우클릭 [열기]
Section 3 · 실습 파트 1

Supabase 5분 컷 (DB 준비)

백엔드 서버 구축 없이, 클라우드 PostgreSQL에 3줄 SQL로 테이블 완성

-- Supabase SQL Editor에 복사해서 Run 클릭! create table todos ( id bigint generated by default as identity primary key, title text not null, is_completed boolean default false, created_at timestamp with time zone default timezone('utc'::text, now()) not null ); alter table todos enable row level security; create policy "Public Access" on todos for all using (true) with check (true);
💡 핵심 메모: Project Settings → API에서 Project URL과 anon public key 2개만 메모장에 복사해둡니다.
Section 3 · 실습 파트 2

AI에게 던지는 마법의 프롬프트

안티그래비티에게 명확한 역할과 재료(.env)를 쥐어줍니다.

🗣️ 수강생 프롬프트 예시

"Supabase를 연동한 모던 다크모드 투두리스트 웹앱을 만들어줘.
1. 할 일 추가, 완료 체크(취소선), 삭제 기능이 Supabase todos 테이블과 실시간 연동되어야 해.
2. .env 파일에 Supabase URL과 KEY를 넣을 수 있도록 설정해줘.
3. 패키지 설치부터 로컬 개발 서버 실행까지 완료해줘."

✨ 한 줄 더 지시하기의 맛
"완료 체크할 때 폭죽(confetti) 애니메이션 나오게 해줘"
🔍 실시간 브라우저 검증
안티그래비티가 직접 브라우저를 열어 UI 동작을 자동 확인
Section 3 · 실습 파트 3

GitHub 푸시 & Vercel 1분 배포

로컬 내 컴퓨터 안에서 돌던 웹앱을 전 세계 인터넷으로 배포합니다.

1️⃣
GitHub 저장소 생성
GitHub Desktop에서 [Publish repository] 원클릭 푸시
2️⃣
Vercel Import
Vercel 로그인 후 방금 올린 저장소 선택 (Import)
3️⃣
환경변수 입력 & Deploy
VITE_SUPABASE_URL
VITE_SUPABASE_ANON_KEY
값 붙여넣고 [Deploy] 클릭!
🎉 첫 번째 감동의 순간: 스마트폰으로 배포된 Vercel URL을 열어 할 일을 추가해 보세요!
