복사 → 안티그래비티에 붙여넣기 → [디자인] 한 줄 채우기 
Vite + React로 투두리스트 웹앱을 지금 열려 있는 폴더에 바로 만들어줘. (하위 폴더를 만들지 마)

[데이터베이스]
- Supabase를 사용해. 테이블은 이미 만들어져 있으니 새로 만들거나 SQL을 작성하지 마.
- 테이블 이름: todos
- 컬럼
  - id: 자동 증가 번호
  - title: 할 일 내용 (문자)
  - is_completed: 완료 여부 (true / false)
  - student_no: 내 번호 (숫자)
  - created_at: 만든 시간 (자동)

[환경변수]
- 프로젝트 폴더에 .env 파일을 만들고 아래 3줄을 그대로 넣어줘.

- 코드에서는 import.meta.env로 읽어서 사용해.
- .gitignore에 .env를 꼭 넣어줘.

[기능] 이 4가지만 만들어줘.
1. 추가: 할 일을 입력하면 student_no에 VITE_STUDENT_NO 값을 넣어서 저장
2. 조회: student_no가 VITE_STUDENT_NO인 할 일만 최신순으로 보여주기
3. 수정: 할 일을 클릭하면 완료 / 미완료 바꾸기
4. 삭제: 삭제 버튼을 누르면 지우기
- 모든 조회 · 수정 · 삭제는 반드시 student_no가 내 번호인 것만 대상으로 해.

[디자인]

다 만들면 npm install, npm run dev로 실행하고 브라우저에서 화면을 확인해줘.
