[디자인]

위 디자인으로 Vite + React 투두리스트 웹앱을 지금 열려 있는 폴더에 바로 만들어줘. (하위 폴더를 만들지 마)

[순서] 반드시 이 순서대로 해.
1. 폴더에 아무 파일도 먼저 만들지 말고, 이 명령으로 프로젝트부터 만들어: npm create vite@latest . -- --template react
2. 그다음 .env 파일을 만들고 아래 3줄을 그대로 넣어.

3. .gitignore에 .env를 추가해.
4. 기능을 만들어.
5. npm install 후 npm run dev는 백그라운드로 실행하고, 브라우저에서 화면을 확인해줘.

[데이터베이스]
- Supabase를 사용해. 테이블은 이미 만들어져 있으니 새로 만들거나 SQL을 작성하지 마.
- 테이블 이름: todos
- 컬럼: id(자동 번호), title(할 일 내용), is_completed(완료 여부 true/false), student_no(내 번호), created_at(자동)
- 환경변수는 import.meta.env로 읽어.

[기능] 이 4가지만 만들어.
1. 추가: insert할 때 student_no에 VITE_STUDENT_NO 값을 숫자로 넣기
2. 조회: student_no가 내 번호인 할 일만 최신순으로
3. 수정: 할 일을 클릭하면 완료 / 미완료 바꾸기
4. 삭제: 삭제 버튼으로 지우기
- select · update · delete 모두 반드시 .eq('student_no', 내 번호)를 붙여.

3배포

로컬에서 잘 되면 복사 → 안티그래비티에 붙여넣기 
Vercel CLI(npx vercel)로 이 프로젝트를 배포해줘. git은 사용하지 마.

1. npx vercel whoami로 로그인 상태를 확인하고, 로그인이 안 돼 있으면 npx vercel login을 실행해서 화면에 나온 링크를 나에게 알려줘. 내가 브라우저에서 승인할게.
2. npx vercel link --yes로 프로젝트를 만들어.
3. 아래 3개 환경변수를 Production에 등록해. 이미 있으면 덮어써. (예: npx vercel env add 이름 production --value 값 --yes --force)

4. npx vercel deploy --prod --yes로 배포하고, 배포 주소를 알려줘.

4수업 끝나면 (공용 PC)

안티그래비티에 붙여넣기 → 브라우저의 GitHub · Vercel도 로그아웃 
npx vercel logout 을 실행해서 Vercel CLI에서 로그아웃해줘.
